# Third-party material and redistribution notes

The repository contains the original paceval SDK public interface files `paceval_main.h` and a minimally adapted public integration implementation `paceval_main.cpp`. Their existing notices are preserved. No license for the paceval runtime binary is granted by this research package, and the required external shared library is **not** included. Consult the official paceval website and the supplied SDK notices before further redistribution or commercial integration.

All included measurement-feature and binary-event data are synthetically generated by the accompanying C++ code. They are not derived from actual meteorological forecasts or observations. The conceptual hero image is generated art and not real geographic or scientific data. Numerical research plots are generated from the paceval output CSVs. The paper references third-party scientific and data-service websites for background only and redistributes no external weather data.
