# Independent technical audit and scope

This document is part of the reproducible scientific audit, not the public engine-to-engine accuracy comparison. Every mathematical input is synthetic; none is a measured factory or laboratory wafer.

The C++ application creates 56 versioned paceval expressions in two successive calculation stages, plus three explicit wafer-statistic graphs. Stage A computes independent film and mask rates and derivatives, stage B computes dependent film depth, selectivity, quality score and bounds. The host copies numerical values between stages, aggregates cross-wafer point values, checks file schemas and retains result files. No independent Python reference feeds the published paceval results.

`src/verify_reference.py` independently recreates the Arrhenius-pressure-spatial response as NumPy array arithmetic, verifies all 22 published scalar quantities, checks all 50 wafer summary groups, and also evaluates a fixed representative selection with 80-decimal-place mpmath. Detailed differences are retained exclusively in `results/independent_reference_audit.json`.

The quality gate uses a *hypothetical* depth tolerance, minimum selectivity, mask thickness and nonuniformity limit. The `ACCEPT`, `REVIEW` and `REJECT` text in the example trace is a software interpretation of these synthetic quantitative margins and is never a fab recipe qualification. No claims about real mask erosion or true selectivity are supported.

The local C++ executable actually links to the external original compatible shared library, not the MCP service. The external shared library is excluded from the GitHub package. Result and graph counts are generated by the live executable and are not added together across fresh re-validation runs.
