# Reproducible research evidence

`mcp_observed_main_selected.csv` is a **selected decimal transcription of actually returned remote paceval MCP 4.26 graph outputs** for each of the 81 deterministic synthetic candidates. It has intentionally fewer columns than all 28 graph outputs; it is not a lossless binary SDK archive.

`mcp_tinc_observed.csv` contains eight actual remotely reported pointwise TINC bounds. The four contact allocations were chosen to illustrate both passing and failing candidate margins. It does not provide a proof for uncertain friction coefficients or all possible geometry values.

`execution_evidence.json` documents the two true sequential mathematical stages: 243 contact vectors, ten contact formulas, 81 candidate vectors and 18 aggregate formulas. The recorded main-stage total is **3888 graph-point evaluations**, with all reported error numbers zero. Separate operator and TINC checks are never added to that main total.

`operator_mcp_selftest.json` records 21 additional operator test results with the verified negative remainder and mathematical modulo sign semantics. The exact expressions and the remote graph handle identifiers for main formulas are in `src/formula_manifest.json`.

`high_precision_validation.json` is generated by `validation/high_precision_reference.py` from the archived actual result CSV and the independent Python 90-digit geometrical model. Any numerical comparison details are for technical audit only, not a claim of a measured advantage over native implementations.

Actual original SDK local execution is **not** documented because the compatible Linux shared library was unavailable. When supplied and linked, `src/robot_grasp_wrench_paceval.cpp` evaluates both stages locally and writes a distinct `results/local_sdk_results.csv` without overwriting the recorded MCP observations.
