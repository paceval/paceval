# paceval SDK integration and redistribution boundary

This research package includes unmodified or minimally integrated `src/paceval_main.h` and `src/paceval_main.cpp` obtained from the original paceval SDK in the companion research environment. Their original copyright and licensing notices are retained. The *externally provided compatible Linux shared library* is **not** included in the public ZIP; users must obtain it independently under applicable permissions.

This sample is a synthetic mathematical proof of concept. It is neither a certified utility planning tool nor an official implementation of IEEE 1547 or related interconnection standards. `src/grid_hosting.cpp` and the Python validation and publication scripts are demonstration code with explicit scope and assumptions.
