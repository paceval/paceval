# Input Schema and Reproducible Conventions

Input and output use UTF-8, comma fields, LF endings, dot decimals, and mandatory exact header names. Text IDs are limited to the generated safe `TRnnn` pattern. All floating CSV numeric values must be **finite decimal literals**, with optional sign and scientific exponent, not paceval expression strings. A field such as `1+2` is rejected before the original numeric conversion API is called. Empty fields, NaN/Inf, locale-dependent thousands separators, and extra columns cause errors. Text serialization uses the real SDK's `paceval_dConvertFloatToString`; preserve machine values separately when exact byte archival is required.

`transformer_parameters.csv`: one row per asset. Columns `asset_id,rated_A,lossR,topRated_K,hotRated_K,n,m,tauOil_h,tauHot_h,coolFactor,initTop_K,initHot_K,limitHS_C,limitOil_C,limitFAA,limitLoad,refTemp_C`. Unitless: R, n, m, cooling multiplier, relative FAA threshold, relative current threshold. Rise values are K, temperatures °C, time constants h, rated current A. `initTop_K` and `initHot_K` are illustrative initial conditions rather than measured thermal equilibrium. The model constrains positive rated current and time constants, nonnegative loss ratios and hot-rise constants, cooling multiplier >0, `m>=0.55` so the derivative remains finite at zero current, and physically meaningful temperatures.

`transformer_profiles.csv`: `scenario,asset_id,hour,ambient_C,current_A,rated_A,dt_h`. `hour` is the integer step index within a scenario; real duration is `dt_h`, here 1 h. `ambient_C` is bounded from -75 to 110, current and rated values are A, and profiles use bounded synthetic current. All 48 transformer identifiers are required for each hour and each scenario; generator output is strictly ordered. Values represent hypothetical operating conditions, not historical transformer records.

`hotspot_timeseries.csv`: the two models' original paceval outputs at every input record, including cumulative aging expressed in **110 °C equivalent hours**, temperature limits in K margins and a Boolean `compound_guard` equal to 0 or 1. The Boolean guard is a mathematical illustration and must not be mapped to a real protection device.
