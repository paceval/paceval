# Execution outputs and provenance

These files were written by the compiled C++ application using the genuine paceval 4.25 SDK, except for `high_precision_audit.json` which was generated by an independent Python reference.

- `screening.csv`: one row per (synthetic input, model version), including paceval-computed capture, loading, heat contributions, signed limit margins and derivatives.
- `model_comparison.csv`: actual paceval multi-graph comparisons, not merely host arithmetic.
- `formula_manifest.csv`: all registered domain graphs and their precise source expressions.
- `math_execution_inventory.csv`: Graph execution owners, use cases, API paths and verified status.
- `execution_evidence.json`: original main-run machine-readable counts; graph calls and cases are separate populations.
- `native_audit.csv`: independent C++ cross-check sample.
- `high_precision_audit.json`: independent mpmath check outcomes; numerical tolerances/details are not in the public Whitepaper or README.

CSV floating-point values are printed through the official paceval conversion API. They are human-readable scientific representations, not asserted to be lossless IEEE-754 binary archives. To reproduce the calculations, use the original input CSV plus the same compiled SDK and the explicitly versioned equations.
